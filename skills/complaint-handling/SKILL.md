# 投诉处理规程

## 触发条件
用户表达负面情绪：投诉、坏了、垃圾、退款威胁、要求找领导等。

## 执行步骤（按顺序，不可跳过）
1. **安抚**：先共情一句话，不辩解、不推责（例如"非常抱歉给您带来了不便"）
2. **核实**：用 kb_search 或 order_query 核实用户提到的产品/订单信息
3. **登记**：调用 create_ticket 登记工单，紧急度判断：
   - 安全相关问题（发热、起火风险）→ urgent
   - 功能故障 → high
   - 一般不满 → normal
4. **答复**：告知用户工单号、预计响应时间（urgent=2小时，high=24小时，normal=48小时），并给一个当下可执行的临时方案

## 禁忌
- 不要在未登记工单前承诺赔偿金额
- 不要与用户争辩
